# 0xBots Command Reference

This file documents the available commands and brief descriptions for each 0x::CODEX bot.

## 0xCODEX (`codex`)
- /start - Initialize 0x:: and enter the system
- /codex - Retrieve a 0x:: core statement from the CODEX
- /law - Return a 0x:: governing principle (The Law)
- /state - Display the current execution state
- /observe - Output a market observation snapshot
- /signal - Check if an execution window exists
- /stats - View channel statistics and milestone progress
- /null - View the NULL profile (The First Observer)
- /void - View the VOID profile (Entropy Coordinator)
- /og - View the OG profile (Culture Interface)
- /prime - View the PRIME profile (Probability Engine)
- /root - View the ROOT profile (Infrastructure Layer)
- /gen - View the GEN profile (Genesis Protocol)
- /nexus - View the NEXUS profile (Multi-Chain Coordinator)
- /decode - Submit answer to current cipher puzzle and unlock lore fragments
- /codex_scan - View your quest progress and CODEX Operator status

## 0xOG (`og`)
- `/help`: List OG-specific commands
- `/history`: Show OG archive / memorable posts
- `/rank`: Show OG rank/status for a user
- `/lore`: Display OG lore and origins

## 0xVOID (`void`)
- `/help`: Void-friendly command list
- `/void`: Invoke the void response (fun/rollicking)
- `/silence`: Make the bot quiet for a chat
- `/lore`: Display VOID lore and voice

## 0xGEN (`gen`)
- `/help`: List content-generation commands
- `/generate`: Generate a message or creative prompt
- `/imagine`: Create an image prompt (links to assets)
- `/lore`: Show GEN's creative lore

## 0xPRIME (`prime`)
- `/help`: Admin and premium commands list
- `/announce`: Broadcast an announcement to channels (admin)
- `/deploy`: Trigger a deployment hook (admin)
- `/lore`: Show PRIME lore and directives

## 0xL1NE (`l1ne`)
- `/help`: Utility commands for L1NE
- `/shorten`: Shorten a URL or text line
- `/format`: Apply line-formatting helpers
- `/lore`: Show L1NE personality

## 0xNEXUS (`nexus`)
- `/help`: NEXUS connector and on-chain utilities
- `/tx`: Lookup a transaction hash
- `/balance`: Check an address balance
- `/lore`: Show NEXUS connector lore

## 0xNULL (`null`)
- `/help`: Null's helper commands
- `/ping`: Ping the bot and get a pong
- `/echo`: Echo a message back (debug)
- `/lore`: Show NULL's lore

## 0xROOT (`root`)
- `/help`: Root-level admin commands
- `/restart`: Request a controlled restart of services (admin)
- `/status`: Get overall system status and health
- `/lore`: Show ROOT's governance lore

## 0xERR (`err`)
- `/help`: Error reporting and debug
- `/report`: Report an error to maintainers
- `/logs`: Retrieve recent bot logs (admin)
- `/lore`: Show ERR's troubleshooting lore
